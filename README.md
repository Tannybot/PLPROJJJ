# PLASS

Programming Language Assessment & Suitability Simulator is a full-stack decision-support platform for evaluating programming languages against software project requirements.

The project includes:

- SaaS-style Next.js interface with dark glassmorphism UI
- Multi-step simulation form
- Animated AI-like analysis stream with processing states
- Weighted recommendation engine for Python, Java, JavaScript, PHP, C#, C++, Go, and Rust
- Comparison dashboard with radar, bar, and trend charts
- Heatmaps, progress meters, and visual scenario simulations
- Educational explanations, did-you-know cards, company usage, and language timelines
- Gamification layer with XP-ready achievement badges and replay history
- Knowledge base pages
- Admin console scaffold
- PostgreSQL Prisma schema for users, simulations, languages, criteria, scores, reports, and bookmarks
- Express REST API
- PDF export
- Docker support

See [docs/SETUP.md](docs/SETUP.md) for setup instructions.
